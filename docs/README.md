# Confido documentation

Confido **0.2.0** is the current development target. Provisional Confido
0.3/0.4 labels were never released; their historical artifacts and commit
records retain the original identifiers. The [migration guide](migration-0.2.md)
is the only current Confido migration guide.

| --- | --- |

| [Revision plan](revision-0.2.md) | Scope, provenance, component boundaries, acceptance and extraction checkpoint. |
| [Coverage matrix](revision/coverage.md) | Claims mapped to implementation, tests and remaining limits. |
| [Independent rerun](revision/rerun.md) | Reproduction steps and evidence to retain. |
| [Reference registry stage](revision/reference-registry-stage.md) | Manual GENXT endorsement and future OIDC publication path. |

| [Walkthrough](revision/walkthrough.md), [roadmap](revision/roadmap.md) | Demonstration narrative and future work. |

The acceptance records describe specific 2026-11-23 runs. They do not
validate later edits or a public deployment. For the current serialized
contracts, see the [schema catalog](../schemas/README.md); for the evidence
transcript, see the [protocol README](../protocol/README.md).
